# Brave Android 候选版 105：关闭开发检查

此版本是个人定制版的实验性预发布，非 Brave 官方发行版。APK 与已完成交替验收并安装的候选版 105 完全一致。

下载附件 `Brave-ARM64-DcheckOff-105.apk`。适用于 ARM64，最低 Android 10（API 29）；实际验收设备为一台 Android 16 Redmi 手机，未完成所有支持版本的兼容性测试。

## 相对上一轮定制基线的变化

- 关闭原生开发检查：`dcheck_always_on=false`、`enable_expensive_dchecks=false`，明确 `dcheck_is_configurable=false`。普通 `CHECK` 保留。
- 原基线已经是 Release，`is_debug=false`，Java 断言也原本关闭。
- 除升级编号外，本轮没有混入其他功能源码、内核版本、广告过滤资源或安全接口配置变更。Shields 资源包与基线逐字节相同。
- APK 从 581,930,100 字节缩小至 442,467,358 字节，减少约 **23.97%**。这是已经确认的收益。

这里的“上一轮基线”指本地定制版 101，不是仓库早期的 Phase 0 包，也不是官方商店版本；此预发布不是零源码改动的官方原版。

## 交替验收结果

同一手机按 A1（原定制版 101）→ B1（候选 103）→ A2（原内容 104）→ B2（候选 105）测试。103 与 105 仅升级编号不同；104 是原 101 内容的更高编号对照包。

| 画质 | A1 原定制 | B1 关闭检查 | A2 原内容复测 | B2 关闭检查复测 |
|---|---:|---:|---:|---:|
| 360p30 掉帧率 | 20/2702，0.740% | 35/2704，1.294% | 36/2709，1.329% | 39/2704，1.442% |
| 1080p60 掉帧率 | 166/5406，3.071% | 2/5410，0.037% | 2/5413，0.037% | 3/5391，0.056% |

每个样本计时 90 秒，播放同一视频的 60–150 秒区间；预先缓冲、固定画质、静音、1 倍速、未登录无痕页、严格 Shields，计时期间断开调试连接。八个有效样本均使用 VP9 硬件解码，未记录等待、停滞或媒体错误。掉帧来自网页视频计数，不是独立屏幕合成测量。

**未证实稳定的掉帧改善，也未正式证明无性能回归。** 360p 候选样本略高于相邻对照；样本量较小，预热、准备时长和温度存在差异。A1 的电池温度约 32°C，后续约 34–35°C，不能把第一次高清差距直接归因于关闭开发检查。

启动后约 4.20–4.48 秒的菜单点击检查 **12/12 通过**；这是指定时点的输入响应检查，不是首次可交互时间。保存的测试记录未发现新增崩溃或 ANR。四轮已有广告脚本的合成输入检查均通过，但不代表所有真实 YouTube 广告已验收。

## 已知限制与下一步

- **Safe Browsing 实际危险网页告警尚未通过验收。** 后续待处理的告警修复没有混入此包。
- 浏览器上游安全修复完整对照、完整启动验收和完整恢复演练尚未完成；继续使用候选通道。
- 高清视频准备阶段仍出现下载缓慢，约 5–6 MB 的部分视频分段耗时约 60–104 秒。预缓冲后的掉帧数据不代表首次播放或连续切换体验。
- 翻译的既有限制未处理；真实广告、登录、直播、锁屏播放、画中画、耗电和长时间稳定性没有在此轮全面验收。
- 此次发布提供手动下载入口，不代表浏览器已具备自动安全更新。下一步先定位视频分段下载瓶颈，并继续补齐安全告警与更新流程。
